Supervised learning is a type of machine learning where the model is trained on labeled data.

Classification is used for categorical outputs, while regression is used for continuous outputs.

Common algorithms include Linear Regression, Logistic Regression, Decision Trees, and Support Vector Machines.

Overfitting occurs when a model learns the training data too well, including its noise, and performs poorly on new, unseen data.

A Perceptron is a fundamental unit of a Neural Network that is also a single-layer Neural Network. Perceptron is a linear classifier. Since it uses already labeled data points, it is a supervised learning algorithm. The activation function applies a step rule (convert the numerical output into +1 or -1) to check if the output of the weighting function is greater than zero or not.
